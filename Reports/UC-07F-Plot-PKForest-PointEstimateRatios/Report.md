# UC-07F Plot generation: PK Forest Point Estimate of Ratios

## Summary
This use case validates point-estimate PK forest ratio plots using PO / IV comparisons within each UC07 population.

## Assertions
- Derives the ratio configuration from the UC07C forest sheet.
- Uses PO scenarios as numerators and matching IV scenarios as referenceScenario denominators.
- Calls runPlot with plotPKForestPointEstimateOfRatios.

## Result files
- Report.md
- UC07F_PK_Forest_PointEstimate_Ratios.qmd
- Exported PK forest ratio plot files
