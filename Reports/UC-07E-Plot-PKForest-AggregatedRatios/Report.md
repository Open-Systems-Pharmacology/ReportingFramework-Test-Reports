# UC-07E Plot generation: PK Forest Aggregated Ratios

## Summary
This use case validates aggregated PK forest ratio plots using PO / IV comparisons within each UC07 population.

## Assertions
- Derives the ratio configuration from the UC07C forest sheet.
- Uses PO scenarios as numerators and matching IV scenarios as referenceScenario denominators.
- Calls runPlot with plotPKForestAggregatedRatios.

## Result files
- Report.md
- UC07E_PK_Forest_Aggregated_Ratios.qmd
- Exported PK forest ratio plot files
